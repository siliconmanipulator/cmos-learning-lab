# CMOS Learning Lab

Dependency-free HTML/CSS/JavaScript teaching app. Open index.html locally, or use GitHub Pages.

- Separate NMOS / PMOS 3D construction and top layout build animations
- Pale embedded body/well regions, saturated implants, optional labels/layers
- Voltage lab: Vg, Vd, Vb, |Vt0| sweeps; cutoff, linear, saturation and pinch-off
- Inverter net highlighting, contact stack, guided introductory lessons

The voltage lab is an ideal long-channel square-law educational model, not a SKY130 SPICE model. It excludes leakage, channel-length modulation and short-channel effects. Dimensions and charge thickness are illustrative. See the in-app model notes and references.
